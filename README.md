# Afonso Mendes — Portfolio

Personal portfolio site, live at [afonsomendes.github.io](https://afonsofm.github.io/afonsomendes.github.io/](https://afonsofm.github.io/afonsomendes.github.io/)).

A single-page site showcasing my background in Telecommunications & Informatics Engineering, professional experience, education, projects, and extracurricular activities.

## Sections

- **About me** — skills overview (programming, networks, telecom, tools, languages, soft skills)
- **Experience** — professional/internship history
- **Education** — academic background
- **Projects** — featured projects with images and tags
- **Activities & Volunteering** — extracurricular involvement
- **Awards & Distinctions** — honors and recognitions, with photo galleries
- **Contact** — ways to get in touch

## Features

- Fully responsive layout (desktop and mobile)
- Scroll-based nav highlighting and smooth-scroll navigation
- Fade-in animations on section scroll
- Image lightbox for project galleries
- Automatic duration labels for date ranges (e.g. "Sep 2025 — Jan 2026 · 5 months")

## Tech Stack

Plain **HTML, CSS, and vanilla JavaScript** — no build step or frameworks. Fonts via Google Fonts (Instrument Serif, Syne, DM Sans, Inter).

## Project Structure

```
index.html                  # entire site (markup, styles, scripts)
images/                     # photos and project screenshots (organized in per-project subfolders)
CV_AfonsoMendes_ENG.pdf     # downloadable CV
```

## Running Locally

Just open `index.html` in a browser, or serve it locally:

```bash
python3 -m http.server
```

Then visit `http://localhost:8000`.

## Deployment

Hosted via **GitHub Pages** directly from the `main` branch.
